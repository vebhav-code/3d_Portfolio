## Brand & Style

This design system embodies high-performance computational craftsmanship. Tailored for an elite Backend Developer & AI Engineer, it conveys systemic mastery, architectural rigor, and understated intelligence. The identity balances industrial software reliability with cutting-edge artificial intelligence exploration.

The aesthetic fuses **Modern Technical Minimalism** with **Atmospheric Luminescence**. Clean, dark slate surfaces are punctuated by precise, low-spread luminescent glows (indigo, cyan, and violet) that mimic quantum compute interfaces, compiler outputs, and server racks. 

Key attributes:
- **Architectural & Exact:** Monospaced data tags, structural gridlines, and strict spacing convey technical credibility.
- **Atmospheric Depth:** Dark neutral canvases layered with varying levels of surface absorption and faint refractive borders.
- **Disciplined Energy:** Vivid indigo and cyan accents are used purposefully for semantic state indicators, data paths, and interactive triggers, never as superficial decoration.

## Colors

The palette is engineered exclusively for an immersive, reduced-eyestrain dark environment. The canvas utilizes deep charcoal-slate shades rather than pure black, retaining visual density and accommodating subtle luminous interactions.

- **Primary (`#6366F1` - Electric Indigo):** Represents logic, core backend architecture, and primary calls to action.
- **Secondary (`#06B6D4` - Cyber Cyan):** Represents active telemetry, real-time data streaming, latency metrics, and API connectivity.
- **Tertiary (`#8B5CF6` - Neural Violet):** Reserved for Machine Learning, deep learning models, neural weights, and AI inference badges.
- **Neutral (`#0B0F17` - Deep Void Slate):** Foundational backdrop.

### Supporting Tone System
- **Surface Canvas:** `#0B0F17` (Deep Void)
- **Surface Layer 1 (Card/Container):** `#111827` (Charcoal Slate)
- **Surface Layer 2 (Raised/Interactive):** `#1F2937` (Elevated Zinc)
- **Border / Subtle Divider:** `rgba(255, 255, 255, 0.08)`
- **Border Active / Glowing:** `rgba(99, 102, 241, 0.35)`
- **Text High-Contrast:** `#F9FAFB` (98% lightness for critical headlines)
- **Text Secondary:** `#9CA3AF` (Muted technical metadata)
- **Text Code / Accent:** `#E0E7FF` (Indigo tint for code syntax)

## Typography

The typography pairings contrast the sharp, neutral geometry of **Inter** for conversational prose and structured headlines with **JetBrains Mono** for architectural code blocks, technical parameters, and system chips.

Rules for implementation:
- **Headlines:** Must maintain tight tracking (`-0.02em` to `-0.03em`) to deliver a dense, editorial tech presence.
- **Labels & Tags:** Rendered in **JetBrains Mono** uppercase or code case (`camelCase` / `snake_case`) with widened tracking (`+0.04em` to `+0.06em`) to echo terminal outputs and IDE inspect panels.
- **Code Hierarchies:** Technical metrics (e.g., `p99 < 12ms`, `CUDA 12.2`, `PyTorch`) must always utilize JetBrains Mono to clearly separate execution data from narrative copy.

## Layout & Spacing

The structural layout utilizes a **12-column dynamic grid** anchored to a maximum container width of `1280px` to maintain focused readability on ultra-wide screens.

- **Desktop (>= 1024px):** 12 columns with `1.5rem` gutters and `2rem` outer page margins. Architectural showcases and project cards map across 4, 6, or 8 columns.
- **Tablet (768px - 1023px):** 8 columns with `1.25rem` gutters and `1.5rem` canvas margins. Asymmetrical showcases fold down to dual balanced columns.
- **Mobile (< 768px):** 4 columns with `1rem` gutters and `1.25rem` safe-area canvas margins. Complex metric dashboards collapse vertically into continuous single-column card stacks.

Internal component rhythm follows a strict 4px base increment (`0.25rem`), anchoring cards, parameter grids, and terminal snippets to a cohesive mathematical cadence.

## Elevation & Depth

Visual hierarchy does not rely on traditional muddy drop shadows; instead, it is constructed through **Tonal Stacking**, **Micro-Borders**, and **Atmospheric Radiance**.

1. **Base Plane (Z: 0):** Background surface (`#0B0F17`). Unbroken, absorbing light.
2. **Structural Plane (Z: 1):** Project and system cards (`#111827`) rimmed with a precise `1px` translucent border (`rgba(255, 255, 255, 0.08)`).
3. **Elevated & Focused Plane (Z: 2):** Flyouts, dropdowns, active code inspect drawers, and hover states (`#1F2937`).
4. **Radiant Bloom Effects:** On hover or active execution states, containers project a subtle, tinted ambient spread (`box-shadow: 0 0 24px -4px rgba(99, 102, 241, 0.25)`). Cyan glows are paired with data ingress/streaming states, while violet glows accent neural inference blocks.
5. **Backdrop Blurs:** Navigation headers, floating action docks, and sticky metric bars utilize frosted glass filtering (`backdrop-filter: blur(12px)`) over an 80% opacity dark slate base.

## Shapes

The design system enforces a **Soft-Chiseled geometry (`roundedness: 1`)**. 

- Standard inputs, buttons, and chips use a `4px` (`0.25rem`) radius.
- Cards, code panels, and architecture diagrams use `8px` (`0.5rem`) (`rounded-lg`).
- High-level modal sheets and canvas frames scale up to `12px` (`0.75rem`) (`rounded-xl`).

This subdued rounding preserves the rigid, engineered discipline of developer tooling (terminals, telemetry graphs, IDEs) while eliminating aggressive raw brutalist corners. Pill-shaped or fully rounded circular UI elements are strictly avoided, except for 1:1 circular metric progress nodes and user status indicators.

## Components

### Buttons
- **Primary:** Background in primary indigo (`#6366F1`), high-contrast light text (`#FFFFFF`), `4px` border radius, padding `0.5rem 1rem`. Monospaced or bold Inter. Hover produces a subtle cyan/indigo rim highlight and `box-shadow: 0 0 16px rgba(99, 102, 241, 0.4)`.
- **Secondary / Outline:** Background in transparent charcoal slate with a `1px` border (`rgba(255, 255, 255, 0.15)`), text in neutral light. Hover shifts the border to Indigo and fills the background with `rgba(99, 102, 241, 0.08)`.
- **Command / Terminal Button:** Dark surface (`#1F2937`), JetBrains Mono font, displaying keyboard shortcuts (`⌘K` or `Ctrl+K`) styled in muted contrast.

### Chips & Badges
- **Tech Stack Badges:** Rendered in `label-sm` (`JetBrains Mono`). Inactive badges: `#111827` surface with `#9CA3AF` text and faint border.
- **AI / ML Focus Badges:** Faint violet background (`rgba(139, 92, 246, 0.15)`), text in `#C4B5FD`, border `rgba(139, 92, 246, 0.3)`.
- **System Health / Live API Badges:** Integrated with a pulsating 6px green/cyan dot indicating real-time service uptime.

### Project & Technical Showcase Cards
- Encased in `#111827` slate with a hairline `1px` border (`rgba(255, 255, 255, 0.08)`).
- Divided into two distinct areas: an interactive architecture overview/code preview block followed by metric parameters (e.g., *Throughput: 45k req/s*, *Latency: 8ms*, *Model: Llama-3-Fine-Tuned*).
- Interactive hover transitions the border to `rgba(99, 102, 241, 0.4)` and lifts the card subtly by 2px without excessive motion.

### Code & Terminal Blocks
- Background styled in `#070A0F` (darker than canvas).
- Top terminal header containing fake macOS/Linux status dots or active directory title (`~/projects/distributed-rag/main.py`).
- Syntax highlighting restricted to Electric Indigo, Cyber Cyan, Neural Violet, and muted zinc comments for visual cohesion.

### Form Inputs & Terminal Command Line
- Text inputs employ `#0B0F17` backgrounds, inset borders (`1px solid rgba(255, 255, 255, 0.1)`), and `JetBrains Mono` text for direct terminal-like input.
- Focus state brings a sharp `1px` cyan border and an outer ring glow of `rgba(6, 182, 212, 0.25)`.

### Selection Controls (Checkboxes & Radios)
- Sharp `4px` radius checkboxes and circular radios utilizing the primary indigo fill upon selection, containing high-contrast white checkmarks. Unchecked state features an empty slate cavity with a low-opacity border.
